### hey, i'm Q

i write software for cars. mostly keeping old car tools alive that people still use but nobody maintains, plus my own stuff for the cars in my garage.

lifelong coder, calgary. my test car is an acura RDX.

**what i'm working on**

- **[FreeSSM](https://github.com/cuedown/FreeSSM)**: free subaru diagnostics. the original went quiet in 2024 so i'm keeping a fork going: native mac build, a 32-bit windows build for tactrix cables, and the community PRs that were sitting unmerged. grab the [test build](https://github.com/cuedown/FreeSSM/releases).
- **[BuildScout](https://github.com/cuedown/buildscout)**: mac app for planning a project car around what you want to build, not the badge.
- honda/acura tools from the RDX (logging, a mac J2534 bridge). going public once they're tested.

**how i work**

- nothing ships until it's been tested. if it's only been on a simulator, the release says so.
- credit goes to whoever found it first.
- no emissions deletes, immobilizer bypasses or odometer stuff. don't ask lol

got a car tool that's broken or abandoned? open an issue on it and tag me.
